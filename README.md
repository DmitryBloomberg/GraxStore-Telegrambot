# GraxStore Telegram Bot

Бот-магазин на Aiogram 3, который загружает каталог Supreme, Nike и Zara, сохраняет его в
`./data/products`, а пользователей и заказы — в JSON-файлы.

## Запуск

```bash
chmod +x start.sh
./start.sh
```

При первом запуске скрипт запросит токен бота и Telegram ID администраторов,
создаст `.venv`, установит зависимости и запустит `bot.py`. Токен и ID
сохраняются в закрытый файл `.env`.

## Хранилище

* `data/users/<telegram_id>.json` — профиль и корзина пользователя;
* `data/orders/<номер>/order.json` — заказ с зафиксированными ценами и статусом;
* `data/products/<номер>/price.json` — цена товара и рассчитанная стоимость;
* `data/products/<номер>/1.jpeg`, `2.jpeg` и т. д. — фотографии товара;
* `data/settings.json` — состояние магазина, доставка, наценка и курс.

Каталог обновляется автоматически до запуска polling. В каталог входят Supreme,
Nike (мужские lifestyle-кроссовки) и Zara (мужская новая коллекция). Если сайт временно
недоступен, старый каталог не удаляется. В админ-панели есть ручная
переустановка позиций: после успешного парсинга старый каталог атомарно
заменяется новым. Стоимость доставки увеличивается на введённую администратором
сумму только для новых позиций/заказов; цены уже оформленных заказов сохраняются
в `order.json`.

## Команды

`/start`, `/products`, `/orders`, `/help`, `/admin`.

В `bot.py` реализованы заказы, корзина, админ-меню на `/start`, управление
этапами заказов («Оформлено», «Ожидает отправки в Россию», «Доставка на склад»,
«Готово к выдаче», «Выдано»), откат этапа, заморозка заказа и переход к чату
пользователя. Также есть статистика с расходами, блокировка пользователей,
экспорт/импорт пользователей ZIP, удаление заказа и переустановка каталога.

При закрытом магазине кнопки «Товары» и «Максимальный бюджет» показывают
сообщение с каналом открытия магазина вместо каталога.

Каталог отправляется страницами по 5 товаров. Перед списком можно выбрать
категорию (штаны, аксессуары, куртки, кофты, обувь и другие доступные) или
бренд. Кнопка «Максимальный бюджет» в
главном меню отбирает позиции по итоговой цене с доставкой.

`start.sh` работает как простой supervisor: если процесс бота завершился с
ошибкой, он автоматически запускается снова через несколько секунд. Пауза
настраивается переменной `RESTART_DELAY`.

После нажатия «Оформить заказ» пользователь получает банк, карту, получателя и
сумму перевода. Затем он отправляет чек документом или фотографией. Чек
попадает администраторам с кнопками «Подтвердить» и «Отклонить», а решение
сохраняется в заказе и отправляется пользователю.

Реквизиты можно задать через `/admin` → «Реквизиты оплаты», либо до запуска
через переменные `PAYMENT_BANK_NAME`, `PAYMENT_CARD_NUMBER` и
`PAYMENT_RECIPIENT` в `.env`. Если реквизиты не заданы, бот не показывает
фиктивные данные и просит обратиться в поддержку.
